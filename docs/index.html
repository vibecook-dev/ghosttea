vibecook / terminal runtime

Ship the Ghostty experience inside your app.

A terminal runtime for your app. Ghostty's terminal core, a Rust daemon, and GPU renderers for Electron and iOS. You build the product. ghosttea draws the terminal.

Embed it.

Needs Electron 35 or later and React 19.

Install

The Electron bridge, the React surface, and the daemon binary.

npm install @vibecook/ghosttea-electron @vibecook/ghosttea-react @vibecook/ghosttead

Main process

Start the daemon and hand the window its ports.

Renderer

A whole terminal workspace, with splits.

import { GhostteaElectronBackend } from "@vibecook/ghosttea-electron/main";
import { ghostteadPath } from "@vibecook/ghosttead";

const backend = new GhostteaElectronBackend({
  mode: "managed",
  daemon: { binary: { kind: "executable", path: ghostteadPath() } },
});
await backend.start();
window.webContents.on("did-finish-load", () => backend.attachRenderer(window.webContents));
import {
  GhostteaProvider,
  createGhostteaTerminalRuntime,
  waitForGhostteaRendererPorts,
} from "@vibecook/ghosttea-react";
import { GhostteaWorkspace } from "@vibecook/ghosttea-react/workspace";

const runtime = createGhostteaTerminalRuntime({ ports: waitForGhostteaRendererPorts(), platform });

<GhostteaProvider runtime={runtime}>
  <GhostteaWorkspace platform={workspacePlatform} />
</GhostteaProvider>;

The preload line and the two small platform adapters are in the API guide.

How a frame reaches the screen.

The daemon shapes the text and sends a display list. Your app's main process and your React tree never touch a frame.

What you get.

  • Ghostty's core

    libghostty-vt 1.0 keeps the state: escape sequences, reflow, selection and scrollback.

  • Real text shaping

    Ligatures and wide characters, shaped natively before they reach the GPU.

  • A workspace

    GhostteaWorkspace gives you splits, zoom and settings. Or place one TerminalSurface yourself.

  • Ghostty config

    The same file syntax and 602 colour themes. Key coverage is partial.

  • Automation that yields

    Scripts and agents can type, but their input is refused if a person typed first.

  • A daemon owns the PTYs

    ghosttead runs your shells in its own process, on macOS and Windows.

Shared sessions.

Open a desktop session from another desktop or from an iPhone. The host sends terminal state, so every device draws sharp text at its own size.

It travels over your tailnet on truffle, and your app supplies the truffle sidecar.

What it needs

Node 22 or later and Rust 1.88 or later. The first run compiles the daemon with Cargo.

shell
git clone https://github.com/vibecook-dev/ghosttea.git
cd ghosttea
npm install
npm run fetch:ghostty-vt
npm run dev

Status.

macOS and Windows
Release-gated in CI. Prebuilt binaries cover Apple silicon and x64 Windows only: there is no Intel Mac, arm64 Windows or Linux build yet.
iOS
Implemented and tested on devices. Release qualification is still open; see the qualification record.
SSH
Exists on iOS only, and is not approved for production yet.
Images
The Kitty graphics protocol is not implemented.
